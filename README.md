# Fonctionnalités 🧠 RAM DISPLAY

 
Outil de surveillance de la mémoire vive (RAM) en temps réel.

### Fonctionnalités
* Affiche la mémoire totale et utilisée en Go.
* Calcul automatique du pourcentage de charge.
* Indicateurs visuels de charge (Vert/Jaune/Rouge).
